Accueil

Point d'entrée simple pour utiliser l'outil selon votre rôle dans l'animation du processus PS3.

Logique de l'outil : il aide à appliquer le cycle d'animation du processus : planifier les actions, suivre leur réalisation, collecter les preuves, traiter les écarts, préparer les revues et décider des améliorations. Toutes les données sont désormais partagées en temps réel entre le pilote, les co-pilotes et la personne ressource.

Tableau de bord

Vue d'ensemble du processus : suivi des actions, alertes, pièces justificatives et décisions à prendre.

Mode d'emploi rapide : 1) connectez-vous avec votre compte, 2) ajoutez les actions, NC, réclamations, preuves ou revues, 3) utilisez le tableau de bord pour repérer les points critiques, 4) exportez les données si vous souhaitez garder une copie. Les données sont partagées instantanément avec les autres membres de l'équipe PS3.
